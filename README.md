# Experimental Acoustics

A NVSE plugin mod for Fallout New Vegas, introducing EAX-based environmental effects via DirectSound OpenAL (DSOAL). Uses native acoustic space records on cells and their audio environment type. 

Produces natural reverb based on the current worldspace, for exteriors and all interiors, affecting effect sounds (gunshots, physics, voices, radios, …), also works when in dialogue. All UI sounds, menu sounds, and the Pip-Boy are excluded.

Inspired by *Reverb and Ambiance Overhaul* for Fallout 4 (developed by MM137).
